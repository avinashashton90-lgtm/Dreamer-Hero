# Architecture: file responsibilities

## Platform and performance
- Three.js + Vite browser game. Target: **phones in landscape**. Desktop works via keyboard/mouse fallback.
- Hosted on **GitHub Pages** (Vite `base: './'`, output in `dist/`).
- Performance: renderer pixel ratio capped at **2** (`CONFIG.render.maxPixelRatio`) and **adaptive** (`render.adaptive`: below `lowFps` 45 for 2 s it steps down by 0.25 to `minPixelRatio` 1, above `highFps` 57 for 2 s back up; a resize keeps the adapted ratio), **no heavy shadows** (no shadow maps; use blob/fake shadows if needed), low-poly placeholders, fog to limit draw distance. **Draw zones** (`world.zones`, `CONFIG.world.zones`): the forest side (terrain grid, river, swamp, town, giant trees, forest trees, trail edges, forest obstacles / walls) is drawn only while the camera is west of `forestMaxX` 185 and the desert side (dunes, scenery, castle) only east of `desertMinX` 125 — their big meshes are never frustum-culled; the cave and its cliffs are in both. The boss on guard is not drawn while the hero is further than `boss.drawRange` 100 from the arena. The sandstorm is lightened for phones (110 streaks, 18 smaller clouds). The game loop uses `THREE.Timer` (the deprecated `Clock` is gone); three.js is built into its own chunk (`vite.config.js`). Gearhaven: ~75–125 draw calls and ≤ ~170k triangles on screen in the ride, ~95 in the courtyard (Tick alone is 21 meshes; the looks add a sky dome, 3 point lights and the floor shader) (headless swiftshader, Pixel 7 landscape). See PLAYTEST.md for the last full bug check.

## Files
## Architecture (one file per system, all in `/src`)
| File | Responsibility |
|---|---|
| `config.js` | **All tunable numbers** + the `DIALOGUE` object (all text/dialogue). |
| `state.js` | Game state machine (`intro/play/cutscene/gameover/ending`) with enter/exit listeners. |
| `world.js` | Map layout (forest + desert tracks, `activeTrack`), `solidsNear` (rock / wall normals near a body), fadeable cave rocks (`fadeSets`, `cameraMeshes`), sunset blend (`setSunset`), desert dunes/scenery/castle (`loadDesertTerrainModel()`, `loadDesertSceneryModels()`, `loadCastleModel()`), `surfaceAt`, `isHazard(x, z)`, foliage fade (`makeFadeMaterial`), terrain (`heightAt`, hills, ford), sky, river, buildings, trees, trail edges, cave rocks, colliders; `loadTerrainModel()`, `loadBuildingModels()`, `loadGiantTreeModels()`, `loadForestTreeModels()`, `loadTrackEdgeModels()`, `loadRockModel()`, `loadCaveModel()`, `loadCaveArchModel()`, `loadObstacleModels()`, `loadMistModel()`; obstacles and forest walls (`placeObstacles`, `loadForestWallModels()`, `laneAt` / `safeLateral` / `gapZone`). |
| `track.js` | The ride trail: `filletPolyline` (straights + arcs) → spline → arc-length samples; `at(s)`, `headingAt`, curvature, grid-indexed `nearest` (s, lateral offset), `distance`. |
| `hero.js` | Hero movement, gravity, jump assist, platform/wall collision, respawn at last safe spot, dodge roll + invincibility, hurt knockback + hit reaction, death fall (`die()`), scripted puppet/drink for cutscenes; `loadHeroModel()` → the Mixamo hero (AJ, a schoolboy in a cap and hoodie) or, if loading fails, the placeholder rig (primitives; posed procedurally). Flash glow / red flicker / hurt blink; costume extras only with `CONFIG.heroCostume`. |
| `heroModel.js` | The Mixamo hero: `loadMixamoHero()` (load, scale, clips, Lazarus Pit cup in the hand; costume pieces only with `heroCostume`) and `HeroAnimator` (state → clip, crossfades, scrubbed timed clips, throw arm layer, straddle, exhaustion slump). |
| `mixamo.js` | FBX loading for Mixamo files: fetch with progress (or `readFile` in Node), texture downsizing, `retargetClip()` by bone name (root motion, yaw fix, bone filter), `mapTime()` key-frame scrubbing. |
| `combat.js` | Melee combo, soft lock-on (ring), hit resolution and feedback events (`onHit`: damage number, shake, hit-stop) — `loadLockRingModel()`, `loadDizzyModel()`. Targets implement `position, radius, height, hp, maxHp, alive, takeHit(), paralyze()`. |
| `lives.js` | Hearts (half hearts allowed) and respawns: `damage()`, `spend()` (Flash cost, never lethal), `setHearts()`, `resolveDeath()` → 'respawn' / 'gameover'. |
| `camera.js` | Third-person follow camera with yaw/pitch orbit, screen shake, blocked-view slide-in / raise / swing, never-inside guard (`insideSolid`, boulder raycasts), hero fade when squeezed in (`heroOpacity`), tree-zone distance/pitch, close over-the-shoulder riding view with speed/gallop FOV, collision with trunks, rocks, buildings and leaves; a gentle smooth wind shake in the sandstorm (`wind`). |
| `input.js` | `TouchRouter` (touches by identifier, hold buttons), `HoldTimer` (Dismount press-and-hold), enlarged button hit areas, cancel/lost-touch handling), joystick, camera drag, Attack / Jump / Dodge / ability buttons (corner layouts on foot / riding from `CONFIG.input.layout`, `buttonLayout()`; uses-left badges (capped at 99, none at 0), greyed when unusable, `shakeAbility`), Mount (on foot), Dismount (small, top right, hold with a ring, `setDismountButton`) and Gallop (hold, with stamina bar), keyboard (WASD/Space/J/K/1-3/E/Shift, debug G/H) & mouse; unified input state. |
| `ui.js` | DOM overlays: exhaustion vignette + weary/heal hearts (`setExhaustion`), cinematic view (letterbox, dialogue box, Skip), ending title + summary, quest panel, hearts + life icons, boss health bar, Victory banner, gem counters (current count; pulse on unlock), the Gearhaven ride's gear counter (`setGears`), top-left toast, Flash screen flash (`screenFlash`), floating damage numbers, respawn/death fades, controls hint, rotate-phone message, Game Over (Retry) / ending screens. |
| `cutscene.js` | Slide-based intro cutscene with tap-to-advance + Skip. |
| `cinematic.js` | Reusable in-engine cutscenes: camera moves (with fov; `follow` re-evaluates a tracking shot every frame), typewriter dialogue, waits, callbacks, tap/Skip, `shake`; the camera guard (distance from characters, ground, solids, fades). |
| `fade.js` | `setObjectOpacity()` (fade a whole model, additive glows untouched) and `characterBodies()` (AJ / Amy / the horse for the cutscene camera). |
| `story.js` | End of Part 1 flow: girl's cutscene trigger + steps, joining up and the desert ride, exhaustion (fatigue), the Lazarus Pit scene (trigger, `pitSteps`, scripted walking/drink/heal tweens, `finishPit`), the sandstorm chase (`desertChaseActive`, `chaseTime`, `chaseOver`, `stormLevel`, `chaseHit`, `restartChase`), the castle-gate cinematic (`startGateScene`, scripted horse path, `gateSteps`, `finishGate`), ending, stats, debug jumps (`debugGate`), `resetAll()` (Play Again). |
| `sandstorm.js` | The sandstorm: `loadSandstormModel()` (instanced wind streaks + dust clouds with per-instance fade, sky veil, warm tint, castle glow), `Sandstorm` (strength easing, gusts, the clear trail corridor, fog blend, camera wind shake, `particlesInCorridor()`). |
| `gate.js` | The castle-gate scene's parts: `CastleGate` (the castle's two gate leaves open / slam, 4 skeletons staged in a line and thrown aside as the horse passes) — `loadGateFxModels()` (bone pieces, dust puffs). |
| `girl.js` | The girl: `loadGirlModel()` → Amy (girlModel.js) or, if loading fails, the placeholder (dress, posed pivots); `loadWitchShadowModel()` (her silhouette / hat-and-staff on the cave wall, only at the cave); `Girl` state flags (frightened, riding, talking, lookAtHero, pointing, walking, kneeling, smiling) → `pose`, `eyesGlowing` (hint or `girlWitchForm`). |
| `girlModel.js` | Amy: `loadMixamoGirl()` (glb + meshopt, FBX clips retargeted, scale, eye glow on the head bone) and `GirlAnimator` (pose → clip, crossfades, talk/point upper-body layers, riding straddle, look round at AJ). |
| `pit.js` | The Lazarus Pit: `loadLazarusPitModel()` (rim, water, faint glow, ripple, aura, heal pulse, additive vapor wisps), `LazarusPit` (`reveal`, `activate`, `pulse`, `dim`, `reset`). |
| `horse.js` | Horse + ride: `loadHorseModel()` (the glTF horse, or the placeholder), mount/dismount, auto-dismount at the arena, routes (`setRoute`), `checkpointHere()`, passenger, ending hold, `scripted` (a cutscene drives it), exhaustion (`fatigue`), side dismount + `mountNow`, hoof prints (`loadHoofPrintModel()`), riding physics, lean/stumble/footfalls, the saddle point (on the seat bone), gallop + stamina, obstacle jump/stumble, water slow-down, dust, splashes, ride checkpoints and respawn-on-horse — `loadDustModel()`, `loadSplashModels()`, `loadCheckpointModel()`. |
