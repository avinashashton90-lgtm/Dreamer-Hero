# Sound files

Every sound in Dreamer Hero has a name. Drop a file with the name below into this folder and the game
plays it instead of its synthesized fallback (the game looks for `.ogg` first, then `.mp3`).
Nothing else to change: the build lists the files it finds here (`virtual:audio-files` in `vite.config.js`;
restart `npm run dev` after adding files if the page does not reload by itself). A missing or broken file
never crashes the game; it just keeps the synthesized sound.

Loops (↻) should loop seamlessly. Short effects work best trimmed tight, mono, 44.1 or 48 kHz.
Volumes are mixed in code (three groups: music, effects, voices — see `CONFIG.audio`).

_This file is generated by `npm run audio:readme` from `src/soundCatalog.js` and the dialogue in `src/config.js`._

## Music (`music_<track>`)

| Section | File | Description |
|---|---|---|
| forest | music_forest.ogg | Forest ride: calm, adventurous |
| bats | music_bats.ogg | Bat attack: tense and faster |
| boss | music_boss.ogg | Cave and boss fight: heavy and dramatic (+ the “intense” layer below half health) |
| pit | music_pit.ogg | Lazarus Pit (and the quiet scenes): soft and magical |
| chase | music_chase.ogg | Desert chase: fast and driving |
| sandstorm | (uses music_chase) | Sandstorm: the chase with a wind layer |
| gate | music_gate.ogg | Castle gate: triumphant |
| ending | music_ending.ogg | Ending screen: gentle |
| gearhaven | music_gearhaven.ogg | Gearhaven (Part 2): clockwork, warm and curious, a ticking pulse |
| layer: intense | music_boss_intense.ogg | Boss under half health: a stronger drum / bass layer (music_boss_intense.ogg) |
| layer: wind | music_chase_wind.ogg | Sandstorm wind over the chase (music_chase_wind.ogg) |

Layer files only play over a music file of their track (they start together, so give them the same length).
